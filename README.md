 

Mobile Store E-Commerce Website

## Project Overview

This project is a simple **E-Commerce web application** developed for the **E-Business course**.
The platform allows users to browse mobile phones, view product details, add items to a shopping cart, and simulate a checkout process.

The project demonstrates the implementation of an **online Business-to-Consumer (B2C) e-commerce model**.

---

## Business Model

**B2C (Business-to-Consumer)**
A business sells products directly to customers through an online platform.

Example platforms that follow this model include companies like **Amazon, Jumia, and Noon**.

---

## Project Features

* User registration and login
* Browse available mobile phones
* View product details
* Add products to cart
* Shopping cart management
* Basic checkout process
